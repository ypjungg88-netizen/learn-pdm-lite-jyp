# Block 2: 공개

> **Phase A 시작 시 그대로 출력한다:**
> ```
> 📖 공식 문서: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
> ```

## EXPLAIN

### 1. 정의

| 용어 | 뜻 |
|---|---|
| GitHub Pages | GitHub 저장소의 `index.html`을 웹 주소로 보여 주는 기능 |
| 설치 한 줄 | 동료가 내 강의 스킬을 설치하는 명령 한 줄 (`npx skills add 내아이디/learn-<주제> --agent claude-code --global --yes`) |

### 2. 무엇을 공개해도 되나

| 공개해도 됨 | 공개하면 안 됨 |
|---|---|
| 가상 데이터와 그 그래프 | 회사 내부 자료 |
| 출처(강의 저장소·파일명) | 비밀번호·API 키·토큰 |
| | 실명·연락처 같은 개인정보 |

### 3. 한 바퀴

만들기 → 배우기 → 배포 → 공유. 이 강의의 결과 대시보드는 GitHub Pages로 공개되고, 짝은 설치 한 줄로 같은 수업을 듣는다. 짝이 들은 뒤 보내 준 점검표로 강의를 고쳐 다시 올린다.

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다.

```
1. pdm-lite-work 폴더의 파일에 비밀번호·키·토큰·
   개인정보·회사 자료가 없는지 점검하고 결과를
   한 줄로 알려 준다.
2. 짝에게 보낼 짧은 메시지를 만들어 줘.
   대시보드 주소, 설치 한 줄, 수업을 부르는 이름
   (/learn-pdm-lite-jyp)을 넣고, 받는 사람이
   할 일을 세 줄로 적어 줘.
3. 메시지는 화면에만 보여 주고 보내지는 않는다.
```

### 확인할 것 (Phase B)

- 점검 결과가 "비밀값·개인정보 0건"이다.
- 공유 메시지에 대시보드 주소, 설치 한 줄, `/learn-pdm-lite-jyp`, 할 일 세 줄이 있다.
- 메시지는 수강생이 직접 카톡으로 보낸다.

막히면 원인을 Claude Code에게 찾게 하는 후속 프롬프트를 준다.

```
점검에서 걸린 항목이 무엇이고 왜 걸렸는지 한 줄씩 설명해 줘
```
