# Block 0: 준비

> ```
> 📖 공식 문서: https://code.claude.com/docs/en/skills · 원본 강의: https://github.com/keerhee/kma-auto-genai-3-1
> ```

## EXPLAIN

### 1. 오늘 쓰는 데이터

| 용어 | 뜻 |
|---|---|
| 설비센서 50건 | 설비 2대 × 25시점(2026-09-15 08:00~16:00, 20분 간격)의 진동·온도·압력. **실습용 가상 데이터** |
| 설비A | 프레스 메인모터 |
| 설비B | 차체 용접로봇 감속기 |
| 진동 (mm/s) | 베어링·회전체 마모, 정렬 불량을 본다. 갑작스러운 증가·추세적 상승이 전조 |

### 2. 왜 데이터를 먼저 준비하나

| 기준 | 손으로 엑셀 열기 | 이번 방식 |
|---|---|---|
| 누가 | 내가 파일을 찾아 복사 | Claude Code가 폴더를 만들고 복사·점검 |
| 확인 | 눈으로 대충 | 행 수·설비 수를 숫자로 확인해 `env_check.txt`에 남김 |

### 3. 현장 장면

라인 정지 1분이 수천만 원이다. 센서가 보내는 작은 신호를 읽으면 큰 사고를 작은 정비로 막는다. 오늘은 그 신호를 설비 두 대의 진동에서 찾는다. (원본: Day5 본 강의 2장)

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다. Phase A 출력 직전에 `{SKILL_DIR}`을 이 스킬 폴더의 실제 경로로 바꿔 보여 준다.

```
아래 순서대로 해 줘.
1. 지금 폴더 안에 pdm-lite-work 폴더를 만든다.
2. {SKILL_DIR}/assets/lab/day5_sensor_50_synthetic.csv 를
   pdm-lite-work 로 복사한다. 원본은 고치지 않는다.
3. python 이 실행되는지 확인한다.
4. 복사한 파일의 행 수와 설비 이름을 세어
   pdm-lite-work/env_check.txt 에 적는다.
5. 결과를 세 줄로 알려 준다.
```

### 확인할 것 (Phase B)

- `pdm-lite-work/day5_sensor_50_synthetic.csv`가 있고 데이터 50행이다.
- 설비가 2개(설비A 프레스 메인모터, 설비B 차체 용접로봇 감속기)다.
- `pdm-lite-work/env_check.txt`가 있다.

막히면 원인을 Claude Code에게 찾게 하는 후속 프롬프트를 준다. 정답은 "정답 보기" 요청이 있을 때만 연다.

```
방금 오류의 원인과 해결을 한 줄씩 설명한 뒤 고쳐 줘
```
